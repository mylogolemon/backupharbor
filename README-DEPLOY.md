# BackupHarbor — Website #19

Independent, static, mobile-responsive guide to resilient personal backups and tested restores.

## Planned domain
`https://backupharbor.site` is a **placeholder until you register and connect the domain**. Domain availability is NOT confirmed. After choosing another domain, replace every occurrence of `backupharbor.site` in `.html`, `sitemap.xml`, `robots.txt`, and other text files.

## Deploy
1. Create a fresh GitHub repository and upload the **contents** of this ZIP (not the outer folder).
2. Import to Vercel as a static site; no build command or framework required.
3. Add your real purchased domain and verify Vercel DNS/SSL status.
4. Test homepage, five random articles, both interactive tools, navigation and mobile.
5. Visit `https://YOUR-DOMAIN/ads.txt`, `/robots.txt`, `/sitemap.xml` and ensure canonical URLs match.
6. Verify ownership in Google Search Console, submit sitemap, and test indexing.
7. Add site in the correct AdSense publisher account; do not request review until pages work and reflect the real publisher details.
